# Komentář k zákonu č. 340/2006 Sb., o činnosti institucí zaměstnaneckého penzijního pojištění

Otevřený komentář k zákonu o činnosti institucí zaměstnaneckého penzijního pojištění — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; působení institucí z jiných členských států, povolení, systém správy a řízení, klíčové funkce, řízení rizik, technické rezervy, investování, přeshraniční činnost a garanční fond.

Konsolidované znění: dokument e-Sbírky `SB-2006-00340_2025-02-15`.
